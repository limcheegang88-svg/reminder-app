# JCB Reminder App

A simple desktop reminder app built with Python and Tkinter.

## Features
- Add reminders with title, date, time, and description
- View reminders in a list
- Delete reminders
- Automatic reminder popup when the due time is reached
- Reminder data saved locally in `reminders.json`

## Run locally

```bash
python JCB_Reminder_App.py
```

## Build executable

```bash
pyinstaller JCB_Reminder.spec
```
