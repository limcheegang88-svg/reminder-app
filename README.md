# JCB Reminder App

A polished desktop reminder app built with Python and Tkinter.

## Features
- Add reminders with title, date, time, and description
- Optional repeat schedules: None, Daily, Weekly, Monthly
- View all reminders in a clean list
- Delete reminders
- Local persistence in `reminders.json`
- Automatic popup notifications when due

## Run locally

```bash
python JCB_Reminder_App.py
```

## Build executable

```bash
pyinstaller JCB_Reminder.spec
```
